# kirsh-portfolio

A personal portfolio site with a recurring spiderman/web visual theme.

## Language

**Web Corner**:
A corner cobweb decoration marking a section as part of the site's spiderman theme.
_Avoid_: web decoration, spider graphic.

**Character Dangle**:
The recurring "dangling spiderman" decorative motif used as an accent across sections. Comes in two motion modes: a **scroll-linked** dangle, whose position tracks scroll progress against a specific point on the page, and an **ambient** dangle, which sways independently of scroll.
_Avoid_: hanging spiderman, spider image.

**Primary Tech Stack**:
The subset of Skills highlighted in the About section as a quick-skim summary, distinct from the full Skills list shown in the Skills section.
_Avoid_: featured skills (implementation-level name for the same idea).
